# Emoception: Selective Affective Layer Fine-Tuning of Video Vision Transformers for Recognizing the Player's Arousal Changes from Game Footage Videos
This is the repository containing the source code and supplement files for the paper "Emoception: Selective Affective Layer Fine-Tuning of Video Vision Transformers for Recognizing the Player's Arousal Changes from Game Footage Videos" 

Please note:    
    1. Some deafult relative path parameters are hardcoded within the script (commented in scripts) , please adjust it yourself if needed.   
    2. Python version = 3.11    


## Dataset
This project uses The Arousal Video Game AnnotatIoN (AGAIN) Dataset, which is licensed under the MIT License. 

You can check and download the dataset here by following their instructions: https://www.again.institutedigitalgames.com/   

In this project, we used their clean_data.csv file and the gameplay videos named [ParticipantID]_[game_name]_[SessionID].webm, which correspond to the entries in a specific game in the clean_data.csv file.

This folder also contains the data preprocessing scripts we used.

The {game_name}_pairs.csv is the helper file generated by the prepare_sample_pair.py.  

The new_{game_name}.csv is the updated helper file generated by the update_paris.py.


## Models
This folder contains all scripts related to our methodology and the content mentioned in the paper. It also includes the experimental scripts and their results.

Please note: The code used for layer selection in the exploratory stage is currently in a separate file to facilitate experimentation. It can be merged later with the fine-tuning code to build the complete framework.
--exploratory.py is the script that compare parameters of a pre-trained and a fine-tuned ViViT model, and the results is save in folder 'Results/exploration'.
--exploratory_resnet.py is the script that compare parameters of a pre-trained and a fine-tuned ResNet model, and the results is save in folder 'Results/exploration_resnet'.

--random_forest_block.py is the script that implements the random forest baseline.

--vivit_lora.py, used for fine-tuning the ViViT model with the LoRA (Low-Rank Adaptation) technique.

--resnet_lstm.py, handling the fine-tuning (full or layer-selective) of the ResNet backbone in a ResNet+LSTM model.

--t-test.py, used for conducting statistical paired $t$-tests to compare F1 performance between SALFT and full fine-tuning, as well as between SALFT and the best-performing baseline on each game set.

--compute_flops.py is the script that measures the FLOPs per iteration of a given model and compares the efficiency per interation of different methods. The results is saved in 'finetuning_efficiency_comparison.csv'.

--efficiency_analysis.py is the script for compare overall computational efficiency between SALFT and Full fine-tuning for ViViT.

--interpreter_new.py is the script to generate the interpreation.

--The script perturbation_new.py is to conduct the perturbation test on our interpretability method and selected baselines. The resutls are in folder 'Results/perturbation_evaluation_results'.

### Results
This folder contains all resutls.

The new folder contains all detailed results from the fine-tuning and exploratory stages.
Within it, method-specific folders are organized as follows:  
exploration & exploration_resnet: Layer selection process and results for ViViT and ResNet, respectively.  
full: Results of full fine-tuning on ViViT.  
vivit_salft: Results of our SALFT method on ViViT.  
resnet_full: Results of full fine-tuning on ResNet50 + LSTM.  
resnet_salft: Results of our SALFT method on ResNet50 + LSTM.  
vivit_lora: Results of fine-tuning ViViT with LoRA.

Note: For each method (e.g., vivit_salft), there are subfolders for each game (e.g., apex). Within these game folders, you will find the distribution of intra-user label entropy (e.g., user_label_entropy_distribution.png) and t-SNE visualizations for feature embedings(e.g., tsne_fold_1.png).

'efficiency' folder contains the computational efficiecy analysis resutls.

'overall_result' folder contains the aggregate results and the statistical paired $t$-test resutls

'perturbation_evalutaion_results' folder contains the results of perturbation test for our interpretability method and selected baselines.

'preliminary_cross_val_results' folder contains the results of preliminary cross-val protocol evaluation.
--cross_val.py is the script that conducts the preliminary cross-val protocol. The results are stored in the folder 'logs'.
